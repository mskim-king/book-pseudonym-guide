# 가명정보 A to Z

![가명정보 A to Z 표지](./assets/cover.png)

**법령·기법·결합 실무 가이드**

개인정보 보호법상 가명정보의 개념, 처리 절차, 가명처리 기법, 결합 및 안전조치, 사례와 FAQ, AI 시대의 가명정보 활용까지 정리합니다.

## 이런 분께 추천합니다

- 개인정보 담당자
- 데이터 분석·활용 실무자

## 이 책의 구성

| 장 | 내용 |
|---|---|
| 01. 가명정보 개요 | 개인정보·가명정보·익명정보의 차이와 가명정보 제도가 생긴 이유, 활용 목적을 알아봅니다. |
| 02. 법령과 가이드라인 | 개인정보 보호법의 가명정보 특례 조항과 개인정보보호위원회 가이드라인을 정리합니다. |
| 03. 가명처리 절차 | 가이드라인의 5단계 절차(사전 준비 → 위험성 검토 → 가명처리 → 적정성 검토 → 안전한 관리)를 따라갑니다. |
| 04. 가명처리 기법 | 삭제·범주화·마스킹·암호화·잡음 추가 등 기법과 재식별 위험을 평가하는 프라이버시 모델을 다룹니다. |
| 05. 가명정보 결합 | 서로 다른 기관의 가명정보를 결합전문기관을 통해 결합하고 반출하는 절차입니다. |
| 06. 안전조치와 사후관리 | 가명정보를 처리한 뒤 지켜야 할 안전조치, 처리 기록, 보유기간과 파기를 다룹니다. |
| 07. 활용 사례 | 보건의료·금융·공공 분야에서 가명정보를 활용한 사례를 살펴봅니다. |
| 08. AI 시대의 가명정보 | 생성형 AI·LLM 환경에서 가명정보를 다루는 새로운 쟁점과 방법입니다. |
| 90. 참고자료 | 용어집, 자주 묻는 질문, 참고 링크를 모았습니다. |
