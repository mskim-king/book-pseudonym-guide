무작위화는 값에 **일부러 작은 변화를 주는** 기법입니다. 개별 값은 정확하지 않게 되지만, 전체 평균이나 분포 같은 **통계적 특성은 거의 유지**됩니다. 정확한 개별 값보다 전체 경향이 중요한 분석에 알맞습니다.

## 요약

- **잡음 추가**: 값에 작은 무작위 값을 더하거나 뺍니다. (키 172cm → 173cm)
- **순열(재배열)**: 한 열의 값을 레코드 사이에서 섞습니다. 열 전체의 분포는 그대로입니다.
- 잡음의 크기는 **분석 정확도와 보호 수준 사이의 균형**으로 정합니다.

## 기법별 예시

| 기법 | 원본 (가상) | 처리 후 | 유지되는 것 | 잃는 것 |
|---|---|---|---|---|
| 잡음 추가 | 구매액 152,000원 | 150,000원 (±5,000 잡음 후 만원 단위) | 평균·분포 | 개별 정확도 |
| 비율 잡음 | 연봉 4,270만 원 | ±3% 범위의 값 | 상대적 크기 | 정확한 금액 |
| 순열 (재배열) | 나이 열을 레코드끼리 섞음 | 열 분포 동일 | 열 하나의 분포 | 다른 열과의 관계 |
| 날짜 이동 | 입원일 2026-03-17 | 사람마다 같은 폭으로 ±n일 이동 | 사람 안에서의 날짜 간격 | 실제 날짜 |

## 예제: 잡음 추가 후 라운딩

`code/01_techniques.py`는 구매액에 ±5,000원 범위의 잡음을 더한 뒤 만 원 단위로 반올림합니다.

```python
"구매액": round(p["구매액"] + random.randint(-5000, 5000), -4)
```

```text
원본 152,000 → 150,000 / 87,000 → 80,000 / 230,000 → 230,000 / 410,000 → 410,000
```

개별 금액은 정확하지 않지만, "40대 회사원 그룹의 평균 구매액" 같은 분석은 충분히 할 수 있습니다.

[[TIP("요령: 사람 단위로 일관되게")]]

의료 데이터의 날짜처럼 **한 사람의 여러 기록**이 있을 때는, 기록마다 다른 잡음을 넣으면 "입원 후 며칠 만에 수술"같은 간격 정보가 망가집니다. **사람마다 같은 이동 폭**을 쓰면 실제 날짜는 숨기면서 간격은 유지할 수 있습니다.

[[/TIP]]

## 주의할 점

| 주의 | 설명 |
|---|---|
| 평균으로 되돌리기 | 같은 값에 잡음을 여러 번 넣어 공개하면, 평균을 내서 원래 값을 추정할 수 있음 → 한 번만 처리한 결과를 공개 |
| 잡음 크기 | 너무 작으면 보호 효과가 없고, 너무 크면 분석이 무의미 → 분석 담당자와 함께 정하기 |
| 관계 파괴 | 순열은 열 사이의 관계(나이와 소득의 관계 등)를 깨뜨림 → 관계 분석이 목적이면 부적합 |
| 수학적 보장 | 일반 잡음은 보호 수준을 수치로 보장하지 않음 → 필요하면 차분 프라이버시(04-8) |

## 실무 체크포인트

- [ ] 잡음 크기를 분석 목적과 함께 정하고 기록했는가
- [ ] 한 사람의 여러 기록에는 일관된 잡음을 썼는가
- [ ] 관계 분석이 목적이라면 순열을 피했는가
