가명정보 결합에는 역할이 다른 두 종류의 기관이 참여합니다. **결합전문기관**은 데이터를 실제로 결합하고, **결합키관리기관**은 같은 사람을 연결하는 열쇠(결합키)를 관리합니다. 이 페이지에서는 두 기관의 역할과, 결합을 신청할 때 기관을 고르는 방법을 정리합니다.

## 요약

- **결합키관리기관**: 한국인터넷진흥원(KISA). 결합키를 받아 **결합키연계정보**를 만듭니다.
- **결합전문기관**: 개인정보보호위원회 또는 관계 중앙행정기관이 지정합니다. 결합, 결합 공간 제공, 반출 심사를 맡습니다.
- 분야별로 지정된 결합전문기관이 다르므로 **우리 데이터 분야에 맞는 기관**을 찾습니다.

## 두 기관의 역할

| 구분 | 결합키관리기관 | 결합전문기관 |
|---|---|---|
| 기관 | 한국인터넷진흥원 | 지정된 공공·민간 기관 (분야별) |
| 받는 정보 | 일련번호 + 결합키 | 일련번호 + 가명정보 |
| 하는 일 | 결합키연계정보 생성·전달 | 결합, 추가 가명처리 지원, 반출 심사 |
| 보지 않는 것 | 가명정보(속성) | 결합키 |
| 파기 | 결합 후 불필요한 자료 지체 없이 파기 | 결합 후 불필요한 자료 지체 없이 파기 |

## 결합전문기관 지정

| 항목 | 내용 |
|---|---|
| 지정 주체 | 개인정보보호위원회 또는 관계 중앙행정기관의 장 |
| 지정 심사 | 전문가로 구성된 지정심사위원회가 지정 요건을 심사 (고시 제정 당시 5명 구성 보도) |
| 분야 | 여러 분야의 공공·민간 기관이 지정되어 있음 (분야와 기관 목록은 공식 누리집에서 확인) |

현재 지정된 결합전문기관 목록과 연락처는 **개인정보보호위원회의 결합 지원 누리집**과 **가명정보 지원 플랫폼**에서 확인할 수 있습니다.

[[TIP("요령: 결합전문기관을 고르는 기준")]]

1. **분야 전문성**: 의료 데이터라면 보건의료 분야 결합 경험이 있는 기관
2. **분석 공간**: 결합된 데이터를 기관 안의 안전한 분석 공간에서 분석할 수 있는지
3. **반출 심사 경험**: 비슷한 데이터의 반출 심사 사례가 있는지
4. **비용·기간**: 결합 수수료와 예상 소요 기간

처음이라면 결합 신청 전에 **상담**을 받는 것이 가장 효율적입니다.

[[/TIP]]

## 예시: 신청 전 준비 목록

```text
[결합 신청 준비 체크리스트 — 예시]
□ 결합 목적 (통계작성 / 과학적 연구 / 공익적 기록보존 중 어디에 해당?)
□ 참여 기관과 각 기관이 제공할 항목 목록 (목적에 필요한 최소 항목)
□ 결합키 생성 항목과 형식 합의 (예: 이름+생년월일+휴대폰, 하이픈 제거)
□ 각 기관 내부의 가명처리·적정성 검토 계획
□ 결합 후 추가 가명처리와 반출 형태 (통계표? 레코드?)
□ 반출하지 않고 기관 내부 분석 공간에서만 분석할지 여부
```

## 실무 체크포인트

- [ ] 우리 분야에 맞는 결합전문기관을 찾았는가
- [ ] 결합 신청 전에 상담을 받았는가
- [ ] 참여 기관 간 제공 항목과 결합키 규칙을 합의했는가
