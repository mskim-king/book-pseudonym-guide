> 📅 **최종 확인**: 2026-11-22

결합된 정보는 원래 각 기관이 가진 정보보다 **훨씬 자세합니다.** 그래서 결합전문기관 밖으로 가져가려면(반출) 추가 가명처리를 하고, 독립적인 위원회의 **반출 심사**를 통과해야 합니다. 이 페이지는 반출 심사를 잘 준비하는 방법을 다룹니다.

## 요약

- 결합신청자는 결합된 정보에 **추가 가명처리**를 하고 반출 심사를 요청합니다.
- **반출심사위원회**는 결합신청자와 이해관계가 없는 **3명 이상 7명 이하**의 전문가로 구성됩니다.
- 반출하지 않고 **결합전문기관 안의 분석 공간**에서 분석한 뒤 결과만 가져가는 방법도 검토할 수 있습니다.

## 반출 심사에서 보는 것

| 관점 | 질문 | 준비할 것 |
|---|---|---|
| 목적 | 결합·반출 목적이 통계작성·연구 등에 맞는가? | 목적서, 분석 계획 |
| 최소성 | 목적에 필요한 항목만 반출하는가? | 항목별 필요성 설명 |
| 재식별 위험 | 결합으로 생긴 준식별자 조합의 위험은? | k-익명성 등 위험 평가 결과 (04-6) |
| 처리 적정성 | 추가 가명처리가 충분한가? | 항목별 처리 내역 |
| 반출 후 관리 | 반출 후 안전조치·기간·파기 계획은? | 안전조치 계획 (06장) |

## 예시: 결합 후 추가 가명처리

카드사 + 통신사 결합 데이터 (가상)

| 항목 | 결합 직후 | 추가 가명처리 | 이유 |
|---|---|---|---|
| 결합ID | C001 | 반출용 새 ID로 다시 대체 | 결합 과정의 ID와 분리 |
| 연령 | 43 | 40대 | 두 기관 정보 조합으로 세밀해짐 |
| 거주 지역 | 역삼동 | 강남구 | 동 단위 + 소비 패턴 → 특정 위험 |
| 월카드사용 | 1,520,000원 | 100만~200만 원 구간 | 금액 + 데이터 사용량 조합 위험 |
| 월데이터 사용 | 12GB | 10~20GB 구간 | 같은 이유 |
| 혼자 튀는 레코드 | 일부 존재 | 로컬 삭제 또는 상위 범주로 | k 기준 미달 |

[[TIP("요령: 통계표로만 반출하기")]]

분석 목적이 "지역별·연령대별 평균 소비"처럼 **집계 결과**라면, 레코드 단위가 아니라 **통계표 형태로만 반출**하는 것이 가장 안전하고 심사도 수월합니다. 이때도 칸 하나에 인원이 너무 적은 셀은 숨기거나 합칩니다.

[[/TIP]]

## 반출 vs 분석 공간 이용

| 방식 | 장점 | 단점 | 알맞은 경우 |
|---|---|---|---|
| 반출 (레코드) | 내 환경에서 자유롭게 분석 | 추가 처리로 정보 손실, 심사 부담 | 반복·장기 분석 |
| 반출 (통계표) | 위험 낮음, 심사 수월 | 분석 자유도 낮음 | 정해진 집계가 목적 |
| 결합전문기관 분석 공간 | 결합 직후 자세한 데이터로 분석 가능 | 공간·시간 제약 | 탐색적 연구, 민감 데이터 |

분석 공간 제공 여부와 이용 조건은 결합전문기관마다 다르므로 상담 시 확인합니다.

## 실무 체크포인트

- [ ] 반출 목적과 항목별 필요성을 설명할 수 있는가
- [ ] 결합으로 새로 생긴 조합 위험을 평가했는가
- [ ] 통계표 반출이나 분석 공간 이용을 검토했는가
- [ ] 반출 후 안전조치와 파기 계획을 세웠는가
