마스킹은 값의 일부를 `*` 같은 문자로 **가리는** 기법입니다. 화면 표시, 상담 기록, 출력물처럼 사람이 보는 곳에서 자주 쓰입니다. 쉽고 직관적이지만, **가린 부분 외의 정보로 다시 알아볼 수 있는지** 함께 확인해야 합니다.

## 요약

- 마스킹은 **부분 삭제의 한 형태**로, 남길 부분과 가릴 부분을 정하는 것이 핵심입니다.
- 분석용 데이터에서는 마스킹보다 **삭제·범주화·토큰화**가 더 알맞은 경우가 많습니다.
- 같은 사람을 계속 추적해야 하면 마스킹 대신 **키 기반 가명ID**(04-4)를 씁니다.

## 항목별 마스킹 예시

| 항목 | 원본 (가상) | 마스킹 예 | 남기는 이유 |
|---|---|---|---|
| 휴대폰 | 010-2345-6789 | 010-****-6789 | 본인 확인 안내 시 끝자리 대조 |
| 이메일 | hong@mail.com | h***@mail.com | 도메인별 분석 |
| 이름 | 홍길동 | 홍*동 | 화면 표시 |
| 카드번호 | 1234-5678-9012-3456 | 1234-****-****-3456 | 카드사 구분, 본인 확인 |
| 주소 | 서울시 강남구 역삼동 123 | 서울시 강남구 *** | 지역 분석 |
| 차량번호 | 12가 3456 | 12가 **** | 차종 구분 |

[[TIP("주의: 마스킹 위치를 통일하기")]]

시스템마다 가리는 위치가 다르면(예: A 시스템은 앞 4자리, B 시스템은 뒤 4자리) **두 자료를 합쳐 전체 번호를 복원**할 수 있습니다. 조직 안에서 항목별 마스킹 규칙을 하나로 정하세요.

[[/TIP]]

## 마스킹 vs 다른 기법

| 목적 | 마스킹 | 더 알맞은 기법 |
|---|---|---|
| 화면에서 일부만 보여 주기 | ✅ 알맞음 | — |
| 지역별 통계 | △ (가린 주소로 집계는 번거로움) | 범주화 (구 단위 열 만들기) |
| 같은 고객의 구매 이력 추적 | ✕ (끝 4자리가 같은 사람이 많음) | 키 기반 가명ID (04-4) |
| 외부 제공 데이터 | △ (남은 부분으로 추측 가능) | 삭제 + 범주화 + 가명ID |

## 예제

`code/01_techniques.py`에서는 우편번호의 뒤 2자리를 가려 `06236 → 062**`로 바꿨습니다. 이처럼 **남기는 부분이 분석에 쓰이는 단위(지역)**가 되도록 정하는 것이 좋은 마스킹입니다.
